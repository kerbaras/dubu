# AGENTS.md

## Layout
- `packages/tofu-wasm`: Go module that builds OpenTofu for `GOOS=js GOARCH=wasm`. Never fork or
  patch OpenTofu sources in place. Platform fixes are Go build overlays generated by `build.sh`
  (`overlay/` holds hand-written replacement files). The module path is
  `github.com/opentofu/opentofu/playground` on purpose, because it may import OpenTofu `internal/`
  packages.
- `packages/tofu-wasm/gen-providers.sh` copies the bundled providers' `internal/` sources under
  `build/providers` (Go forbids importing them otherwise). To add a provider: require it in
  `go.mod`, list it there, and register it in `providers/bundled.go`.
- `packages/runtime`: TypeScript runtime that Go's `syscall/js` talks to (`globalThis.fs`,
  `globalThis.process`, `globalThis.__tofuTTY`). One Go process per Web Worker run.
- `apps/web`: the Vite app. `scripts/sync-assets.mjs` copies the wasm build into `public/tofu`.

## Rules
- Files under 200 lines (hard cap 400), one responsibility per module, pure functions where
  possible, IO at the edges. Nothing over-engineered.
- Libraries live in `packages/`, apps in `apps/`.
- Use the real binary for language behaviour (`validate -json`, `fmt -`, `metadata functions
  -json`, `providers schema -json`) instead of reimplementing HCL semantics in TypeScript.
- Before pushing: `pnpm typecheck && pnpm test && pnpm build`. The runtime tests run the real
  `tofu.wasm` when `packages/tofu-wasm/dist/tofu.wasm` exists.
- Conventional commits. CHANGELOG follows keepachangelog.com.
